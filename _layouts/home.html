The problem

Building an agent is easy. Running many of them in production is not.

Every team that builds agents or a software factory needs the same things: a runtime, sandboxes, gateways for models and tools, identity, budgets, tracing and evals. Platform engineering already solved this for services. I build it once, as a platform, so teams bring their own agents and run them on top.
