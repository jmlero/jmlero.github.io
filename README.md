# jmlero.github.io

Personal portfolio website hosted on GitHub Pages.

## Features

- Modern, responsive design
- Smooth animations and transitions
- Dark theme with gradient accents
- Glassmorphism UI elements
- Fully customizable
- No dependencies - pure HTML, CSS, and vanilla JavaScript

## Customization

Edit `index.html` to customize:

1. **Personal Info**: Update name, title, and description in the hero section
2. **Links**: Modify LinkedIn, email, or add more social links
3. **Skills**: Edit the "What I Do" section with your skills
4. **Colors**: Change CSS variables in `:root` for different color schemes

## Local Preview

Open `index.html` in your browser to preview locally.

## Deploy

Push to GitHub and your site will be live at: `https://jmlero.github.io`
